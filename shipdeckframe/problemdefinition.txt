# __ SECTION PROPERTIES _______________
Rectangular: 0.08×0.04
A = 0.0032 m^2      Area of Cross-section
I = 4.2667 m^4      Second moment of Area

# __ MATERIAL PROPERTIES ______________
Steel:
E=210×10E9 N/m^2    Young's Modulus
ρ=7850     kg/m^3   Density

# __ BOUNDARY CONDITIONS ______________
Fixed bottom-left node  : u=v=θ=0
Pinned bottom-right node: u=v=0

# __ STATIC LOADING ___________________
At Node5, Point Load: F_y -100000 N
           (downward)


# __ FEM MATRIX FORMULATIONS __________
Each Element is considered to have two nodes:
The interpolation polynomials:
        u = N1.u1 + N2.u2       
        
        v = N3.v1 + N4.θ1 + N5.v2 + N6.θ2
        θ = N3'.v1 + N4'.θ1 + N5'.v2 + N6'.θ2


Thus;
        m_e = ∫N'ρN dx
        k_e = ∫B'stiffnessB dx
            axial stiffness   ∝ EA/L
            bending stiffness ∝ EI/L^3

So, finally we arrive:

These are local stiffness and mass matrices that we consider the Element being in horizantal axis.
When the beam axis changes w.r.to the global x-axis we have to transform the matrices according to the orientation angle (ϕ)
    c = cos(ϕ); s = sin(ϕ)
            | c, s, 0, 0, 0, 0|
            |-s, c, 0 ,0, 0, 0|
        T = | 0, 0, 1, 0 ,0, 0|
            | 0, 0, 0, c, s, 0|
            | 0, 0, 0,-s, c, 0| 
            | 0, 0, 0, 0, 0, 1|

        k_e = T'kT
        m_e = T'mT

These are implemented in the utlities.py and can be imprted to use in any file
